**Bonjour!** 🌟

Welcome to **Sunshine Terminal** — the AVF Linux VM gateway for the Sunshine Android App, reimagined as a touch-first, block-based terminal environment where every interaction feels like a gentle breeze through a Parisian garden.

## 🌿 What Makes Sunshine Terminal Special?

Sunshine Terminal isn't your grandfather's CLI. It's a **modern terminal environment** designed for the way we interact today:

### ✨ Touch-Optimized
- Drawer interfaces that slide in with grace
- Panel-based workflows for dual-panel comparison
- Tree views that make navigation feel intuitive
- Gesture-friendly command structure

### 🧱 Block-Based Design
- Modular components that fit together like Parisian patisserie
- Context-aware operations that understand what you're doing
- Visual file management with markdown preview
- Interactive elements that respond with *je ne sais quoi*

### 🛡️ AVF Linux VM at Its Heart
- Full Linux binary support via Android 16 AVF
- Docker container orchestration (when you need it)
- System daemons and services without Bionic path issues
- Isolated hardware-accelerated Debian VM via pKVM/crosvm

### 📁 Smart Workspace Management
- File operations that just make sense
- Markdown-rendering that shows, not just tells
- Create, write, delete, move with confidence
- Tree navigation and depth control

### 🔄 Agent Loop Control
- VM provisioning and security bundles
- Lockdown profiles for outbound allowlisting
- Thermal monitoring and throttle states
- Heartbeat loops with auto-recovery

## 🚀 Quick Start

```bash
# Install and start
git clone https://github.com/highsockscapital/Sunshine-Terminal.git
cd Sunshine-Terminal
npm start   # or: scli status

# Your first commands
scli status          # AVF runtime status & workspace summary
scli workspace       # List files in current workspace
scli vm status       # AVF VM details and capabilities
scli run "<command>" # Execute in AVF Linux VM
```
